# Japan Trip Asset Kit

Private app asset pack for a cute, friendly Japan trip planner.

## Images

- `images/hero-tokyo-sakura.png`: first-screen background or dashboard hero.
- `images/card-ryokan-onsen.png`: hotels, ryokan, onsen, rest-day planning.
- `images/card-tokyo-itinerary.png`: itinerary/day card visual.
- `images/pattern-japan-travel.png`: decorative low-opacity pattern, empty states, headers.
- `images/mascot-suitcase-daruma.svg`: small mascot for empty states and confirmations.
- `images/icon-*.svg`: navigation, labels, and quick action icons.

## Audio

- `audio/tap.wav`: subtle button tap.
- `audio/complete.wav`: checklist or booking saved success.
- `audio/soft-open.wav`: modal/drawer open.
- `audio/ambient-loop.wav`: optional low-volume planning background loop.

## Usage Notes

Prefer SVG icons for UI controls and PNG illustrations for hero/card imagery. Keep generated illustrations decorative and avoid placing important UI text directly on top of high-detail areas without a soft overlay.
